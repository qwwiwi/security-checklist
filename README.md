# security-checklist

Чек-лист безопасности для тех, кто запускает сайты, серверы, API и ИИ-агентов. Плюс готовый промпт и навык, с которыми ИИ-агент сам проверит ваш проект и напишет отчёт.

## Для кого это

Для владельцев небольших проектов: лендинг с оплатой, Telegram-бот или Mini App, сервер с агентом, сервис на Supabase и Next.js. Опыт в безопасности не нужен: каждый термин пояснён, у каждой проверки есть команда или действие, после которого понятно, всё ли в порядке.

Это не замена профессиональному аудиту. Чек-лист закрывает частые и дешёвые ошибки: ключ в git, открытая база, сервер с входом по паролю, агент, которого можно уговорить отправить ваши данные постороннему.

## Главное

Если времени есть только на пять дел, сделайте эти:

1. **Включите вход по аппаратному ключу или passkey** (вход, который нельзя выманить поддельным сайтом) на GitHub, у хостинга, регистратора доменов, в базе данных и платёжной системе. Взлом одного такого аккаунта отдаёт всё сразу.
2. **Поставьте лимит расходов и отдельный ключ на каждого агента и каждый сервер** у ИИ-провайдеров (Anthropic, OpenAI, OpenRouter). Тогда утёкший ключ стоит десятки долларов, а не тысячи, и отключается один, а не все.
3. **Включите в GitHub secret scanning и push protection** (GitHub не даст отправить в репозиторий файл с ключом) и один раз проверьте всю историю репозиториев программой gitleaks.
4. **Если у вас Supabase, включите RLS на каждой таблице** (правила «кто какие строки видит») и проверьте, что секретный ключ `service_role` или `sb_secret_` не попал в код сайта. Это самый частый способ утечки всей базы.
5. **Разделите возможности агентов по правилу трёх ног.** Агент, который читает чужой текст (веб, письма, сообщения пользователей), не должен одновременно видеть ключи и уметь отправлять данные наружу.

## Как пользоваться

Есть три способа, выберите удобный.

**Прочитать чек-листы и пройти их самому.** Начните с [checklist/more-protection.md](checklist/more-protection.md): там меры расставлены по пользе. Потом пройдите таблицы по своей части проекта.

**Отдать промпт агенту.** Откройте [prompts/security-audit.md](prompts/security-audit.md), скопируйте текст из блока и отправьте агенту (Claude Code, Codex), запущенному в папке проекта. Агент ничего не меняет, только проверяет и пишет отчёт. Для настройки защиты сайта в браузере есть отдельный промпт [prompts/csp-hsts.md](prompts/csp-hsts.md): он уже предлагает правки.

**Установить навык.** Навык (skill) – файл с инструкцией, который агент подхватывает сам, когда вы просите проверить безопасность. Установка описана в [skills/security-audit/README.md](skills/security-audit/README.md).

Команды в чек-листах и промптах написаны по документации, но системы у всех разные. Сначала попробуйте их на одном проекте и посмотрите, что они выводят, а потом запускайте везде.

## Что где лежит

| Файл | Что внутри |
|------|-----------|
| [checklist/frontend.md](checklist/frontend.md) | Сайт и браузер: заголовки защиты, секреты в коде страницы, Telegram Mini App, CORS, хранилища браузера |
| [checklist/servers.md](checklist/servers.md) | Сервер, сеть, ssh, бэкапы, API, база данных, платёжные уведомления |
| [checklist/api-keys.md](checklist/api-keys.md) | API-ключи и секреты: хранение, права, лимиты, план «ключ утёк» |
| [checklist/ai-agents.md](checklist/ai-agents.md) | ИИ-агенты: prompt injection, правило трёх ног, минимальные права |
| [checklist/more-protection.md](checklist/more-protection.md) | Меры по соотношению пользы и усилий |
| [prompts/security-audit.md](prompts/security-audit.md) | Промпт для агента: аудит проекта только на чтение |
| [prompts/csp-hsts.md](prompts/csp-hsts.md) | Промпт для агента: проверка и настройка CSP, HSTS и хранилищ браузера |
| [skills/security-audit/](skills/security-audit/) | Навык для Claude Code и Codex: тот же аудит без копирования промпта |

В каждой таблице четыре колонки: что сделать, зачем, как проверить и как часто. Номера проверок (F – фронтенд, S – сервер, A – API, K – ключи, G – агенты) одни и те же в чек-листах, промпте и навыке: в промпте и навыке есть команда или вопрос для каждого номера, поэтому отчёт агента легко сверить с таблицей.
