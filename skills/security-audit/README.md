# Навык security-audit

Навык (skill) – папка с файлом `SKILL.md`, в котором записана инструкция для ИИ-агента. Агент сам открывает её, когда вы просите о подходящей задаче. Этот навык учит агента проверять безопасность проекта: только чтение, без правок, с отчётом по номерам проверок из [чек-листов](../../checklist).

Работает в Claude Code. Codex и другие агенты, которые понимают формат `SKILL.md`, подхватят его так же; папку для навыков смотрите в документации своего агента.

## Установка

Нужен git (программа для работы с репозиториями) и терминал.

1. Скачайте репозиторий:

   ```bash
   git clone https://github.com/qwwiwi/security-checklist.git
   ```

2. Выберите, где навык будет работать.

   Во всех ваших проектах – скопируйте в личную папку навыков:

   ```bash
   mkdir -p ~/.claude/skills
   cp -r security-checklist/skills/security-audit ~/.claude/skills/
   cp -r security-checklist/checklist ~/.claude/skills/security-audit/checklist
   ```

   Только в одном проекте – скопируйте в папку `.claude/skills` внутри проекта:

   ```bash
   mkdir -p путь-к-проекту/.claude/skills
   cp -r security-checklist/skills/security-audit путь-к-проекту/.claude/skills/
   cp -r security-checklist/checklist путь-к-проекту/.claude/skills/security-audit/checklist
   ```

   Чек-листы копировать не обязательно: в `SKILL.md` есть все команды. С ними агент точнее заполняет колонку «Что сделать».

3. Перезапустите агента и проверьте, что навык виден: в Claude Code наберите `/` и найдите в списке `security-audit`.

## Как запустить

Откройте агента в папке проекта (или на сервере, который хотите проверить) и напишите, например: «Проверь безопасность этого проекта». Агент спросит адрес сайта и API, если не найдёт их сам, и вернёт отчёт:

- «Главное» – пять самых опасных находок;
- таблицу по всем проверкам со статусами «ок», «провал», «не смог проверить»;
- вопросы к вам и команды, которые нужно запустить с правами администратора.

Агент ничего не меняет и не печатает ключи. Если вы хотите, чтобы он ещё и исправил найденное, дайте ему отдельное задание после отчёта.

Сначала попробуйте навык на одном проекте и посмотрите, какие команды он запускает: системы у всех разные.

## Если навык не подхватился

- Проверьте путь: файл должен лежать как `~/.claude/skills/security-audit/SKILL.md` (или `.claude/skills/security-audit/SKILL.md` в проекте), без лишней вложенной папки.
- Вызовите навык явно: `/security-audit`.
